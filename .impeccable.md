# Design Context — CodeCraft: Galactic Developer

## Audience
Beginners and intermediate developers learning HTML/CSS/JS through gameplay.

## Use cases
- Complete coding challenges that build a 3D space colony
- Get progressive hints without leaving the game HUD
- Place unlocked buildings and track learning progress

## Brand personality
Educational, encouraging, precise — cosmic colony fiction without cartoonish UI.
Tone: clear and technical when needed, warm without condescension.
Visual direction: industrial-space HUD — deep space blacks, cosmic blue accents, energy yellow highlights. Professional SVG icons only (no emoji chrome). Typography: Space Grotesk for UI, JetBrains Mono for code.
